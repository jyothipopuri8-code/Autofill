    Applications

    Every application the agent has prepared. Only you set the final status; the agent never submits for you.

      Profile

      Facts the agent may use on every application. Leave a field empty if you would rather be asked. Nothing here is sent anywhere except to forms you start an application on.

      Sensitive questions

      Gender, race, disability, veteran status and similar questions. The default is to ask you every time. Choose "Always answer" only for a value you are comfortable giving on every application.

        Answer library

        Reusable factual answers such as desired salary or willingness to relocate. A policy decides whether the agent may fill it, ask you, or never fill it.

          Add or change an answer

          Remembered answers

          Answers you approved while applying. They are reused only for the same question, and are dropped if the resume or profile they depended on changes. Forget any you no longer want.
